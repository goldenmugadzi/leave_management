# BEII V1 Documentation

This folder contains all documentation for the BEII V1 system, organized by category and application.

## Folder Structure

### `/apps/`
Application-specific documentation organized by Django app:
- `ACE2/` - ACE2 application documentation
- `Asset_Register/` - Asset Register application documentation
- `BatteryMaintenance/` - Battery Maintenance application documentation
- `circuit_breaker_maintenance/` - Circuit Breaker Maintenance documentation
- `finance/` - Finance module documentation
- `fault_locator/` - Fault Locator application documentation
- `inspections/` - Inspections application documentation
- `it/` - IT module documentation
- `safety/` - Safety application documentation
- And more...

### `/system/`
System-wide documentation:
- `installation/` - Installation guides and procedures
- `migration/` - Database and system migration documentation
- `deployment/` - Deployment guides and procedures
- `configuration/` - Configuration documentation

### `/development/`
Development-related documentation:
- `api/` - API documentation
- `testing/` - Testing documentation and guides
- `scripts/` - Script documentation
- `troubleshooting/` - Troubleshooting guides

### `/user_guides/`
End-user documentation and guides

### `/technical_specs/`
Technical specifications and architecture documents

### `/external/`
External documents (PDFs, etc.)

### `/other/`
**Temporary folder** - Contains all existing documentation files that need to be organized into the appropriate categories above.

## Documentation Standards

### File Naming Convention
- Use descriptive names with underscores
- Include date prefixes for versioned documents
- Use consistent capitalization

### File Types
- `.md` - Markdown files for text documentation
- `.pdf` - PDF documents
- `.txt` - Plain text files
- `.html` - HTML documentation

## Getting Started

1. Check the `/other/` folder for existing documentation
2. Organize files into appropriate subfolders
3. Update this README as new categories are added
4. Follow the naming conventions for new files

## Contributing

When adding new documentation:
1. Choose the appropriate category folder
2. Follow the naming conventions
3. Update relevant index files
4. Consider cross-referencing related documents
