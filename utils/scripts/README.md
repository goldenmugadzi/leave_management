# Scripts Directory

This directory contains utility scripts for various development and maintenance tasks.

## Migration Scripts

- `manage_all_migrations.py` - Comprehensive migration management
- `migrate_all_assets.py` - Asset-specific migration script
- `make_all_migrations.py` - Migration creation script
- `mark_migration_applied.py` - Mark migrations as applied
- `run_all_migrations.sh` - Shell script for running migrations

## Verification Scripts

- `verify_budget_logic_detailed.py` - Detailed budget logic verification
- `verify_budget_summary.py` - Budget verification summary
- `final_verification.py` - Final verification script

## Data Creation Scripts

- `create_sample_sanction_data.py` - Create sample sanction data
- `create_sanction_tables_manual.py` - Manual sanction table creation
- `create_fault_migration.py` - Fault migration creation

## Debug Scripts

- `debug_role_status.py` - Debug role status issues
- `debug_team_leader.py` - Debug team leader issues

## Utility Scripts

- `scr.py` - General utility script
- `main.js` - JavaScript utility
- `schema.ts` - TypeScript schema
- `scripts.py` - General scripts collection

## Output Files

- `output` - General output file
- `test` - Test output file
- `budget_logic_fix_report.txt` - Budget fix report
- `budget_logic_verification_results.txt` - Budget verification results

## Usage Notes

- **Backup** important data before running scripts
- **Test** scripts in development environment first
- **Review** script logic before execution
- **Document** any customizations made to scripts
