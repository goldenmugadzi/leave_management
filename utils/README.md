# Utils Directory

This directory contains utility scripts and tools created during development and problem-solving.

## Structure

### `/scripts/`
General utility scripts for various tasks:
- Migration scripts
- Verification scripts
- Data creation scripts
- Debug scripts
- Output files from testing

### `/testing/`
Test files created during development:
- Unit tests
- Integration tests
- Feature tests
- Debug tests

### `/setup/`
Setup and configuration scripts:
- Role setup scripts
- Workflow setup scripts
- User setup scripts

### `/fixes/`
Problem-specific fix scripts:
- Bug fix scripts
- Data correction scripts
- Critical issue fixes

## File Types

- `.py` - Python scripts
- `.sh` - Shell scripts
- `.js` - JavaScript files
- `.ts` - TypeScript files
- `.txt` - Output and log files

## Usage

These files are typically created during development and debugging. They should be:
1. **Reviewed** before running
2. **Backed up** if they contain important logic
3. **Cleaned up** when no longer needed
4. **Documented** if they contain reusable logic

## Important Files

- `manage_all_migrations.py` - Migration management script
- `verify_budget_logic_*.py` - Budget verification scripts
- `run_all_migrations.sh` - Migration shell script
- Various test files for different features
